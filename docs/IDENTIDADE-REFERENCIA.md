# Identidade visual da referência

Menu preto #101010, textos claros #E6E2D8 e marca champagne #E4D5B2. Seleção em gradiente dourado #B39A62 / #E8D8A4 / #B59A62 com texto #17140E. Botões principais pretos com texto #EADBB9, borda #927B4E. Fundo de mármore claro reaproveitado dos assets locais do projeto, com tratamento CSS acinzentado. Sem imagem remota, sem alterações no banco ou na autenticação. Cards de indicadores com mármore suave, contorno dourado/grafite e sombra mais definida. Tema escuro preserva pares de texto/fundo e usa textura discreta.

O desenho da textura é o asset do projeto; não é uma cópia pixel a pixel do mármore da captura enviada. Composição e paleta seguem a referência.
